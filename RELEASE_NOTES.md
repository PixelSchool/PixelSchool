# PixelSchool v1.3.0 — Фоновые уведомления, шифрование сессий, исправления интерфейса и Material 3 Expressive 🎓✨

> **PixelSchool** — быстрый, легковесный и эстетичный школьный дневник для системы ЭлЖур (`edu.rk.gov.ru`) на базе **Material 3 Expressive**.

---

### 🌟 Что нового в версии 1.3.0

#### 🔔 1. Фоновые уведомления о новых оценках
* **Автономная синхронизация**: Фоновый сервис (`WorkManager`) периодически проверяет появление новых оценок в журнале даже при закрытом приложении.
* **Информативные пуши**: При выставлении новой оценки приложение присылает уведомление с указанием предмета и балла (например: *«Новая оценка: Алгебра — 5»*).
* **Управление в профиле**: Добавлен удобный переключатель уведомлений прямо на экране профиля.

#### 🔐 2. Надёжное хранение сессии и токенов
* **Отказоустойчивое двухуровневое хранилище**: Устранена проблема неожиданного выхода из аккаунта при сбоях Keystore или блокировке устройства.
* **Автоматическое восстановление**: Сессия сохраняется стабильно, повторный ввод логина и пароля больше не требуется при обычном перезапуске приложения.

#### 🎨 3. Полноценные Material 3 Expressive темы и дизайн
* **5 гармоничных цветовых палитр**: Cobalt (Сапфир), Emerald (Изумруд), Violet (Фиолетовый), Amber (Янтарь), Rose (Розе) со строгим соблюдением тональных контейнеров M3 (`surfaceContainerLowest` … `surfaceContainerHighest`).
* **Идеальные пропорции**: Исправлены отступы и размеры для кнопки «Выйти из аккаунта», блока «О системе» и кнопки «Обновить».
* **Комфортные всплывающие шторки**: Меню информации об уроке и деталях оценок теперь открываются на оптимальные 75% высоты с удобным внутренним скроллом вместо 100% полного экрана.
* **Плавное переключение вкладок**: Устранено визуальное запаздывание элементов при переходе между разделами нижней панели навигации.

#### ⚡ 4. Исправления работы с версиями и расписанием
* **Точная проверка обновлений**: Карточка обновления теперь точно определяет текущую версию приложения через `BuildConfig.VERSION_NAME` и не предлагает повторно скачать актуальный релиз.
* **Мгновенный переход к сегодняшнему дню**: Устранено зависание пейджера на половине пролистывания между вчерашним и сегодняшним днем.

#### 📦 5. Глубокая оптимизация R8 и GitHub Actions релиз
* **Включен R8 / ProGuard**: Уменьшен размер APK и повышена скорость холодного старта.
* **Автоматический релиз**: Готовый APK собирается и подписывается автоматически в GitHub Actions.

---

### 📲 Установка
1. Загрузите файл **`PixelSchool-v1.3.0.apk`** из блока **Assets** ниже.
2. Установите поверх предыдущей версии или с нуля.
3. Авторизуйтесь и пользуйтесь дневником!

*Минимальная версия Android: 8.0 (API 26).*
