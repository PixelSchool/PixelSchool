# PixelSchool v1.0.0 — Первый официальный релиз 🎓✨

> **PixelSchool** — быстрый, легковесный и эстетичный школьный дневник для системы ЭлЖур (`edu.rk.gov.ru`) на базе **Material 3 Expressive**.

---

### 🌟 Что нового в этом релизе

#### 🎨 Material 3 Expressive Design
* **Современные компоненты**: Каноничный M3-индикатор четвертей с плавным скруглением (Pill Shape / `RoundedCornerShape 3.dp`), точно следующий за выбранной вкладкой.
* **Идеальная сетка отступов**: Исправлены вертикальные и горизонтальные промежутки по гайдлайнам Material 3 (12 dp между карточками и блоками).
* **Минималистичный UI**: Убраны лишние дублирующие кнопки в панели навигации расписания, сделан упор на информативность и чистоту контента.

#### 📊 Четвертная ведомость оценок
* **Вся успеваемость за учебный период**: Полноценный просмотр оценок по 1, 2, 3 и 4 четвертям.
* **Авторасчёт среднего балла**: Быстрый анализ успеваемости по каждому предмету и сводный средний балл за период.
* **Многоуровневый фетчинг**: Отказоустойчивый парсинг ведомости с обработкой региональных особенностей ЭлЖур.

#### 📅 Расписание и домашние задания
* **Умное переключение недели**: При переходе на следующую или предыдущую неделю фокус автоматически устанавливается на понедельник.
* **Удобный выбор даты**: Интуитивный выбор дня прямо через интерактивный заголовок недели.
* **Домашние задания**: Чёткое отображение предметов, времени уроков, кабинетов и заданий на дом.

#### 🔐 Безопасность и профиль
* **Авторизация ЕСИА (Госуслуги)**: Бесшовная аутентификация через официальный шлюз без передачи учетных данных сторонним серверам.
* **Динамический профиль**: Автоматическое определение имени, фамилии и школы учащегося.
* **Нулевой хардкод PII**: Кодовая база и история Git полностью очищены от любых персональных данных.

#### ⚙️ Инженерия и оптимизация
* **Чистый стек**: Kotlin 2.0 + Jetpack Compose + Material 3 + Kotlinx Serialization.
* **Без лишнего кода**: Архитектура строго следует принципам YAGNI и Ponytail (минимальный вес APK ~11 МБ).
* **Криптографическая подпись**: Сборка подписана по стандартам схем Android V1–V4.

---

### 📲 Установка
1. Загрузите файл **`PixelSchool-v1.0.0.apk`** из блока **Assets** ниже.
2. Откройте файл на вашем Android-смартфоне (разрешите установку из неизвестных источников, если потребуется).
3. Авторизуйтесь через ЕСИА (Госуслуги) и пользуйтесь удобным дневником!

*Минимальная версия Android: 8.0 (API 26).*
